# 激光房 12×12 控制面板

用于现场 144 点红、绿、关控制。面板通过本机服务向现场 MQTT 发布 `changeState`，不需要浏览器控制台。

需要 Node.js 18 或以上。在此目录先执行 `npm ci`。然后运行 `npm start`，打开 <http://127.0.0.1:8765/>。macOS 也可双击「启动激光面板.command」。

首次打开时先用「全关」建立矩阵，再逐格切换。每格按关、红、绿、关循环。「全红」「全绿」「全关」一次设置全部 144 点。

在现场确认可以操作后，运行 `npm run show` 开始两分钟实机展示。每两秒发布一组，依次用随机横条、竖条和 2×2 方块组成红、绿、关图案，共 60 组。正常结束或按 Ctrl+C 中止时会发送全关。展示期间请使用一个控制入口。切回面板操作前，点一次「全关」同步面板的矩阵。

默认 MQTT 地址为 `mqtt://192.168.10.80:1883`，发射端为 `192.168.10.51`。MQTT 确认表示消息到达现场服务，实际灯光以现场观察为准。
